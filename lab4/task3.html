Теоретичні відомості

HTML

HTML — мова розмітки, яка визначає структуру вебсторінки. За допомогою тегів створюють заголовки, абзаци, посилання, форми та інші елементи.

CSS

CSS використовується для оформлення сторінки: кольорів, шрифтів, відступів, розташування елементів та адаптивного дизайну.

JavaScript

JavaScript додає інтерактивність. Він може реагувати на натискання кнопок, перевіряти відповіді тесту та змінювати вміст сторінки.

DOM

DOM — об'єктна модель документа, яка дозволяє JavaScript знаходити, читати та змінювати HTML-елементи.

Елементи форм

Radio дозволяє вибрати один варіант, checkbox — кілька варіантів, select — вибрати відповідь зі списку, а text — ввести текст.
